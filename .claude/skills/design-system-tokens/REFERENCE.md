# Token reference

Снимок текущих токенов из `src/styles/tokens.css` с подсказками когда какой использовать. Обновляй вручную при добавлении/изменении токенов.

> Если что-то здесь расходится с `tokens.css` — `tokens.css` всегда прав.

## Typography

### Семейства

| Token          | Когда                                                                                                       |
| -------------- | ----------------------------------------------------------------------------------------------------------- |
| `--font-serif` | h1, h2, цитаты на статичных страницах. Editorial-настроение.                                                |
| `--font-sans`  | Body, UI, формы, таблицы, навигация. По умолчанию.                                                          |
| `--font-mono`  | Оформление: логотип, надзаголовки, метки, ID, счётчики. Системный стек, без веб-шрифта.                     |
| `--font-code`  | Только настоящий код: `code`, `pre`, `kbd`, `samp`, обвязка код-блока. Единственный токен с JetBrains Mono. |

### Размеры (`--fs-*`)

`xs (12px) → sm (14px) → base (16px) → md (17px) → lg (20px) → xl (24px) → 2xl (30px) → 3xl (36px) → 4xl (44px)`.

- `--fs-xs` — meta-данные, бейджи, KBD.
- `--fs-sm` — secondary text, footers.
- `--fs-base` — body по умолчанию.
- `--fs-md` — слегка увеличенный body, prose в статьях.
- `--fs-lg` — h4, lead-параграфы.
- `--fs-xl` — h3.
- `--fs-2xl` — h2.
- `--fs-3xl` — h1 типичной страницы.
- `--fs-4xl` — h1 hero/landing.

### Line-height (`--lh-*`) и tracking (`--tracking-*`)

| Token                         | Когда                             |
| ----------------------------- | --------------------------------- |
| `--lh-tight` (1.15)           | Hero-заголовки, h1.               |
| `--lh-snug` (1.3)             | h2, h3.                           |
| `--lh-normal` (1.55)          | UI text, формы, лист-итемы.       |
| `--lh-relaxed` (1.7)          | Body статей.                      |
| `--tracking-tight` (-0.015em) | Крупные заголовки, чтобы плотнее. |
| `--tracking-normal`           | По умолчанию.                     |
| `--tracking-wide` (0.08em)    | UPPERCASE-метки, сокращения.      |

## Colors

### Light/Dark пары

Все цвета имеют counterpart в `@media (prefers-color-scheme: dark)`.

| --------------------- | ------- | ------- | ---------------------------------------- |
| `--color-bg`          | #fdfcf7 | #1a1712 | Базовый фон страницы.                    |
| `--color-bg-elevated` | #f7f3e8 | #221e17 | Карточки, поверхности над bg.            |
| `--color-bg-subtle`   | #f2edde | #2b261e | Фоны hover/selected, code-блоки в prose. |

#### Foregrounds

| Token               | Light   | Dark    | Когда                                               |
| ------------------- | ------- | ------- | --------------------------------------------------- |

| `--color-fg-subtle` | #6f6350 | #9e907a | Третичный (placeholder, вспомогательное). AA на bg. |

| Token                | Light   | Dark    | Когда                                                                                        |
| -------------------- | ------- | ------- | -------------------------------------------------------------------------------------------- |

## Space

`--space-1: 4px → --space-9: 96px` (4-8-12-16-24-32-48-64-96). Шкала под "ритм четвёрки": каждый следующий шаг — заметная, но не двойная разница.

- 1–3 — внутри inline-элементов (gap между иконкой и текстом, padding KBD).
- 4 — стандартный gap внутри карточки.
- 5–6 — gap между карточками, padding контента.
- 7–9 — vertical rhythm между секциями.

## Radii

| Token           | Value | Когда                           |
| --------------- | ----- | ------------------------------- |
| `--radius-sm`   | 4px   | Inline (KBD, маленькие бейджи). |
| `--radius-md`   | 6px   | Кнопки, инпуты.                 |
| `--radius-lg`   | 10px  | Карточки, диалоги, модалки.     |
| `--radius-pill` | 999px | Pill-теги.                      |

## Shadows

| Token             | Когда                                               |
| ----------------- | --------------------------------------------------- |
| `--shadow-soft`   | Hover состояние, лёгкое подъём (карточки в списке). |
| `--shadow-lifted` | Модалки, dropdown'ы, popover'ы.                     |

В dark-mode тени переопределены на `rgba(0,0,0,…)` — не используй их light-значения вручную.

## Layout

| Token           | Value                   | Когда                                  |
| --------------- | ----------------------- | -------------------------------------- |
| `--col-sidebar` | 240px                   | Левая боковая колонка.                 |
| `--col-content` | 720px                   | Основная контентная колонка.           |
| `--col-toc`     | 220px                   | Правая TOC-колонка.                    |
| `--gutter`      | `var(--space-6)` (32px) | Промежутки между колонками.            |
| `--content-max` | 1280px                  | Максимальная ширина контента в layout. |

## Motion

| Token           | Value                            | Когда                          |
| --------------- | -------------------------------- | ------------------------------ |
| `--ease-out`    | `cubic-bezier(0.2, 0.8, 0.2, 1)` | Появление, slide-in.           |
| `--ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)`   | Туда-обратно (hover/un-hover). |
| `--dur-fast`    | 120ms                            | Микро-фидбек (hover, focus).   |
| `--dur-base`    | 200ms                            | Стандартные переходы.          |
| `--dur-slow`    | 320ms                            | Открытие модалок, drawer.      |

В `@media (prefers-reduced-motion: reduce)` все `--dur-*` обнуляются. Если добавляешь новый `--dur-*` — обнули и его.

## Anti-patterns reminder

- ❌ `padding: 14px` — не из шкалы.
- ❌ `color: #946708` — есть `var(--color-accent)`.
- ❌ `--color-text` — есть `--color-fg`.
- ❌ Цвет без dark counterpart.
- ❌ `@apply ...` в CSS.
