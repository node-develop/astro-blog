# Редакторская и фактическая проверка Claude Code Guide

Проверено 8 сентября 2026 года: 14 уроков на русском, 14 английских версий и оба оглавления. Русские уроки переписаны целиком; английские вычитаны и синхронизированы по фактам. Адреса, порядок уроков и исходные даты публикации сохранены. Дата существенного обновления — 2026-09-08.

## Редакторские решения

Вместо повторяющейся истории прошлых ошибок каждый урок объясняет задачу, механизм, пример и способ проверки. Убраны лишние англицизмы из русских заголовков и основного текста: endpoint → адрес/обработчик API, fixtures → подготовленные тестовые данные, blueprint → план проекта, tool call → вызов инструмента, scope → область действия. Skills, hooks и subagents объясняются при первом употреблении. Команды, поля JSON/YAML и пути сохраняют точное написание. История исправлений доступна в Git и аудите от 7 сентября, а не занимает половину учебного материала.

## Границы проверки

Локальный Claude Code: 2.1.263. Проверены справки `claude mcp add --help`, `claude plugin validate --help`, `claude --help`. Собран минимальный плагин из опубликованных фрагментов: validator принимает манифест, с необязательным предупреждением об отсутствии автора. Это проверка формата, а не утверждение о выполненном платном вызове навыка.

Тесты исполняют опубликованный JavaScript hook с правильным и неправильным JSON, проверяют путь с пробелами и другой рабочий каталог, разбирают метаданные плагина/навыка и согласованность всех пар уроков. События реальной платной сессии, MCP-соединение с настоящим поставщиком, бронирование, расходы API и опыт с командой агентов не запускались: эти места обозначены как упражнения и границы учебного проекта.

Денежные суммы и проценты эффективности не выдумывались. Точные тарифы не дублируются в бессрочной таблице: указаны первичные источники и способ сравнения на своих задачах. Сверка документации не гарантирует поддержку каждого режима во всех клиентах и версиях.

## Публикация даты проверки

Схема коллекции уроков теперь сохраняет `updatedDate`. Эта дата передаётся в JSON-LD урока и страницы, Markdown и `lastmod` карты сайта. Исходная дата публикации сохраняется; для уроков без обновления карта сайта и страница используют её. Интеграционный тест проверяет все 28 опубликованных уроков после сборки, отдельные тесты — необязательность поля и прежний вариант без обновления.
