# Personal blog on Astro

Стек (апрель 2026): Astro 5, TypeScript 6 (strict), pnpm 10, PostgreSQL 18, Drizzle ORM, Better-Auth, Tailwind 4, MDX с Mermaid и KaTeX.

## Быстрый старт

```bash
# 1. зависимости
corepack enable && corepack prepare pnpm@10.12.1 --activate
pnpm install

# 2. переменные окружения
cp .env.example .env
# отредактировать .env — минимум DATABASE_URL и BETTER_AUTH_SECRET

# 3. локальный Postgres
docker compose up -d postgres

# 4. миграции
pnpm db:generate   # если менял src/lib/db/schema.ts
pnpm db:migrate

# 5. dev-сервер
pnpm dev           # http://localhost:4321
```

## Публикация статьи

1. `src/content/posts/<slug>.mdx`
2. Заполнить frontmatter (см. `src/content.config.ts`).
3. Markdown + опционально Mermaid-блоки и LaTeX (`$...$`, `$$...$$`).
4. `pnpm dev` → `http://localhost:4321/blog/<slug>`.

Подробнее — в `.claude/skills/new-blog-post/SKILL.md`.

## Social autopost

При публикации статьи автоматически генерируются черновики постов для X-EN, LinkedIn-EN и Telegram-RU через конвейер Writer (Haiku 4.5) → Editor (Sonnet 4.6 с voice card) → Critic (Sonnet 4.6, read-only). Драфты попадают на ревью в `/admin/social`, откуда публикуются per-channel вручную.

Фича выключена по умолчанию (`SOCIAL_DRAFTS_ENABLED=false`). Полный playbook включения и cutover — в [docs/admin/social-cutover.md](docs/admin/social-cutover.md). Spec и план: `docs/superpowers/specs/2026-05-09-social-autopost-design.md`, `docs/superpowers/plans/2026-05-09-social-autopost.md`.

## i18n / Translation Workflow

The site is bilingual: Russian (source of truth) at `/`, English at `/en/`. EN content is auto-generated by `pnpm translate` (Claude Haiku 4.5) and committed to the repo.

**Authoring a new post:**

1. Write the RU post in `src/content/posts/<slug>.md` as usual.
2. Run `pnpm translate` — generates `src/content/posts/en/<slug>.md` with `sourceHash` frontmatter for incremental cache.
3. Review the diff. Spot-check code blocks (must be byte-identical), Mermaid diagrams, and prose quality.
4. Commit RU and EN files together.

**Hand-edits to EN content:**

To preserve a manual edit across future regen runs, set `manuallyEdited: true` in the EN file's frontmatter. The script will skip the file on subsequent runs and warn if the RU source drifts.

To re-translate one file from scratch (overrides both `sourceHash` and `manuallyEdited`):

```bash
pnpm translate -- --force <slug>
```

To re-translate everything:

```bash
pnpm translate -- --force-all
```

**CI guard:** every push runs `pnpm translate:check`, which fails if any RU post lacks a current EN twin. Run `pnpm translate` and commit before pushing.

**Environment:** `ANTHROPIC_API_KEY` must be set in `.env` for `pnpm translate`. CI never calls the API — `translate:check` is filesystem-only.

**Translation cost:** ~$1-2 per full re-baseline (Haiku 4.5); near-zero on incremental runs (only changed files retranslate).

## Деплой

Пуш в `main` запускает `.github/workflows/docker-publish.yml` → билд → пуш в `ghcr.io/<owner>/astro-blog:latest` с тегами из git.

## Claude Code

Проект настроен под Claude Code:

- `CLAUDE.md` — глобальный контекст и стандарты
- `.claude/agents/` — architect, sysanalyst, backender, frontender, critic
- `.claude/skills/` — new-blog-post, astro-component, db-migration, deploy-check
- `.claude/hooks/` — session-start, no-secrets (блокирует .env), format (prettier), notify-stop
- `.claude/settings.json` — permissions + hook registrations

- Git hooks — не пропускаем (`--no-verify` запрещено).
