## Who I Am

Artem Kashuta. 10+ years in development: backend, infrastructure, recent years —
agentic systems and tooling around LLM. Based remotely. I write in Russian,
read and work in English.

## What I Do

- **AI agent engineering** — harness/agent loop, tool design, evaluation, MCP,
  debugging the "context → action → observe" cycle.
- **Backend and distributed systems** — Node.js, TypeScript, PostgreSQL,
  queues, idempotency, observability.
- **Developer tooling** — Astro/Vite-based internal tools, CLI wrappers,
  scripts for the team.
- **DevOps and deploy automation** — Docker, GitHub Actions, GHCR, Dokploy,
  migrations on container startup.

## Stack

- **Languages:** TypeScript, Node.js, some Python.
- **Web:** Astro 5, React (only when islands are needed), Tailwind 4.
- **Database:** PostgreSQL 18, Drizzle ORM, Better-Auth.
- **Infrastructure:** Docker (multi-stage), GitHub Actions, GHCR, Dokploy.
- **AI:** Claude Code (Opus 4.7 / Sonnet / Haiku), Anthropic SDK, MCP servers.
