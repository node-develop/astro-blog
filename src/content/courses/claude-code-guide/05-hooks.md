Навык нужно вызвать, а некоторые действия хочется выполнять автоматически. Например, после изменения файла запускать форматирование. Для этого в Claude Code есть _hooks_ — обработчики событий. Вы выбираете событие и команду, которую приложение должно выполнить.

Начнём с простого обработчика, который сообщает о правке. Так легче проверить настройку, прежде чем подключать к ней настоящие проверки.

## Настраиваем событие

В учебном репозитории добавьте этот раздел в `.claude/settings.json`. Если файл уже существует, сохраните остальные настройки.

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "node \"$CLAUDE_PROJECT_DIR/.claude/hooks/observe-edit.mjs\"",
            "timeout": 5
          }
        ]
      }
    ]
  }
}
```

`PostToolUse` срабатывает после успешного вызова инструмента. `matcher` выбирает инструменты по имени: здесь это Edit и Write. Команде даётся пять секунд. Переменная `CLAUDE_PROJECT_DIR` указывает на корень проекта, поэтому путь не зависит от текущего каталога команды. Пример рассчитан на среду с Node.js и совместимой командной оболочкой.

Создайте `.claude/hooks/observe-edit.mjs`:

```javascript
let input = "";
for await (const chunk of process.stdin) input += chunk;
const event = JSON.parse(input);
process.stderr.write(`Observed tool: ${String(event.tool_name)}
`);
```

Claude Code передаёт обработчику JSON через стандартный ввод — `stdin`. Скрипт читает его и выводит только имя инструмента. Полное событие записывать не стоит: в нём могут быть содержимое файлов и чувствительные аргументы.

## Проверяем запуск

Сначала проверьте скрипт отдельно:

```bash
printf '%s' '{"tool_name":"Edit"}' | node .claude/hooks/observe-edit.mjs
```

В терминале должно появиться `Observed tool: Edit`. Затем откройте Claude Code, проверьте настройку через `/hooks` и попросите изменить безвредный файл. Вывод успешного обработчика не обязательно виден в обычном разговоре; смотрите подробный вывод или журнал отладки. Отдельно передайте скрипту неправильный JSON: он должен завершиться с ошибкой.

## Когда можно запретить действие

Обработчик после изменения не может предотвратить уже сделанную запись. Для проверки до вызова нужен `PreToolUse`. У него код завершения 2 может блокировать действие; правила JSON-ответа зависят от события. Они описаны в [справочнике hooks](https://code.claude.com/docs/en/hooks).

Фильтр Edit и Write также не охватывает запись через Bash. Поэтому обработчик удобен для автоматизации, но не заменяет права доступа и ограничения среды.

Когда наблюдение работает, можно подключить линтер. Проверьте, что он установлен, завершается вовремя и не портит файл при повторном запуске. Далее разберём [подключение инструментов через MCP](/courses/claude-code-guide/06-mcp/).
