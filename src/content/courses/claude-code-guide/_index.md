## Зачем этот курс

Для разработчика, который хочет понимать, где заканчивается ответ модели и начинается ответственность приложения: контекст, инструменты, права, проверка результата.

Курс состоит из 14 коротких уроков. Проходите их по порядку или выбирайте нужную тему. В каждом есть конкретная задача для самостоятельной проверки. Travel Agent — учебная архитектура с тестовыми данными, а не готовый production-репозиторий.

## Ключевые принципы

Разделяйте ответ модели и результат исполнения. Проверяйте инструкции на установленной версии. Сохраняйте свидетельства успешного и неуспешного запуска. Не выдавайте учебную схему за готовый сервис.

## Что изменилось 7 сентября 2026

Исправлены устаревшие настройки, неподтверждённые команды и примеры SDK. Убраны обещания фиксированной экономии, абсолютной защиты через hooks и автоматических блокировок файлов. Карта исправлений — в [уроке 14](/courses/claude-code-guide/14-claims-verification/).

Сохраняйте версию инструмента и результаты упражнений. Ссылка на документацию объясняет контракт; успешный запуск на вашей машине проверяет вашу конфигурацию. Эти виды доказательств дополняют друг друга.

Если заметили ошибку, пришлите точную фразу и воспроизводимый пример через [контакты](/contact/).
