## Зачем этот курс

Claude Code может читать проект, менять файлы и запускать команды. Курс поможет понять, как он выбирает действия, что получает в контексте и как проверить результат его работы.

Материал рассчитан на разработчика, знакомого с терминалом, Git и простым API. Специальные термины объясняются по мере появления. Названия команд и полей настроек сохранены так, как их нужно вводить.

## Как проходить

Начните с первых трёх уроков: работа агента, контекст и инструкции проекта. Затем переходите к навыкам, обработчикам событий и MCP. Вторая половина посвящена помощникам, расходам и сборке учебного приложения.

В каждом уроке есть небольшая задача для самостоятельной проверки. Планировщик поездок использует подготовленные данные: он не делает настоящих бронирований. Отдельного готового репозитория курс не предоставляет.

## Ключевые принципы

Сначала сформулируйте ожидаемое поведение, затем проверьте его на понятном примере. Различайте ответ модели и выполненное действие. Сохраняйте не только успехи, но и ошибки — они показывают, где заканчиваются возможности решения.

Команды и настройки сверены с официальными источниками 8 сентября 2026 года. Версии клиента и условия доступа меняются, поэтому рядом с техническими объяснениями есть ссылки для повторной проверки. Как оценивать такие утверждения самостоятельно, разобрано в [заключительном уроке](/courses/claude-code-guide/14-claims-verification/).
