Хороший CLAUDE.md отвечает на вопросы, которые агент иначе будет решать наугад: где находится нужный код, как запустить проверку и какие ограничения важны для проекта. Пересказ всей документации в корневом файле затрудняет поиск этих ответов.

[Документация памяти](https://code.claude.com/docs/en/memory) рекомендует короткие инструкции. Импорты `@path` загружают текст, а не создают бесплатное справочное хранилище. Ограничение стартовой загрузки MEMORY.md — отдельная механика; его нельзя переносить на CLAUDE.md.

## Минимальный пример

```markdown
# Trip planner

Учебный сервис: поиск по тестовым маршрутам, без бронирований.

## Перед правкой

- Найди обработчик запроса и соответствующий тест.
- Сохрани существующий формат ответа.
- Не добавляй внешние интеграции в задачу про локальную валидацию.

## Проверка

Команды бери из package.json и README этого репозитория.
В отчёте укажи выполненную проверку и её результат.
```

Это исходная заготовка. После создания проекта замените общую строку про проверку точной существующей командой. Не вставляйте `pnpm test`, если такой script не определён.

## Где хранить подробности

Общие ограничения держите рядом с корнем проекта. Специфику подсистемы — рядом с соответствующим кодом или в отдельном справочнике. Процедуру редкой операции можно вынести в skill. Важно различать ссылку на документ и импорт его полного содержимого: они создают разный объём стартового контекста.

Не описывайте эту систему как надёжную таблицу приоритетов, где последнее правило всегда побеждает. Если две инструкции противоречат друг другу, исправьте конфликт в источнике.

## Упражнение: проверить каждую строку

Для своего CLAUDE.md создайте таблицу «инструкция → подтверждение». Для команды подтверждением будет успешный запуск; для пути — существующий файл; для ограничения — реальная причина в архитектуре или договорённости команды.

Удалите инструкции про удалённые библиотеки. Уточните «пиши хорошие тесты» до конкретного поведения. Проверьте, не повторяет ли импортируемый документ уже написанный запрет. Затем попросите агента объяснить порядок работы над небольшой задачей и сравните ответ с намерением автора файла.

## Инструкции не заменяют права

Файл помогает модели выбрать действие, но сам не закрывает доступ к секретам и не запрещает сетевые операции. Для этого нужны настройки исполнения и ограничения среды. Проверяйте их отдельно на тестовых данных.
