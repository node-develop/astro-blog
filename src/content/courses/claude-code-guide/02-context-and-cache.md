Контекст — материал, доступный модели в текущем запросе. История разговора — один из его источников. Prompt cache позволяет повторно использовать обработанный префикс запроса. Кэш не превращает предыдущую сессию в постоянную память и не делает всю работу бесплатной.

Размер доступного окна зависит от модели, аккаунта и провайдера. Прежнее утверждение курса о неизменных 200k и недоступности 1M в `opusplan` устарело: [актуальная конфигурация моделей](https://code.claude.com/docs/en/model-config) описывает другие варианты. Проверяйте активную модель и окно в своей сессии.

## Из чего складывается расход

Для собственного API-приложения удобно разделить четыре величины:

```text
стоимость = обычный вход × его тариф
          + запись кэша × тариф записи
          + чтение кэша × тариф чтения
          + выход × тариф выхода
```

Это схема расчёта, а не тарифная таблица. Берите цены и правила своего провайдера. Сохраняйте usage каждого запроса: история может расти, а доля повторяющегося префикса — меняться. Нельзя умножить один короткий запрос на число итераций и назвать это точной ценой всей сессии.

В Claude Code команда `/cost` относится к текущей сессии, а `/usage` — к ограничениям использования. Полный счёт сверяйте с биллингом. Нюансы разных способов оплаты разобраны в [документации расходов](https://code.claude.com/docs/en/costs).

## Почему кэш перестал помогать

Проверьте, повторяется ли нужная часть запроса, не изменились ли настройки и не истёк ли срок хранения. Не делайте вывод «всё потеряно» по одному cache miss. Следующий запрос может повторно использовать уже созданный префикс; точное поведение устанавливается по usage.

Отдельно проверьте лишний материал. Полный дамп базы, повторный вывод одного файла и ненужные описания инструментов мешают читать историю независимо от тарифов. Выбирайте фрагменты, которые нужны для решения текущего вопроса.

## Упражнение: два одинаковых запроса

В тестовом API-проекте отправьте одну и ту же безопасную задачу с одинаковым префиксом дважды, используя документированную настройку кэша. Сохраните usage и длительность. Затем измените часть префикса и повторите. Подпишите каждый результат, модель и время запроса. Не сравнивайте биллинг подписки с API-тарифом как одинаковые величины.

## Перед очисткой сессии

Запишите исходную задачу, принятые решения, изменённые файлы, проведённые проверки и следующий шаг. Только затем начинайте новую сессию, если старая мешает работе. `/clear` не должен уничтожать единственное описание незавершённой задачи.
