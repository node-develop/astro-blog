MCP задаёт протокол подключения инструментов и данных. Само успешное соединение не доказывает, что инструмент решает задачу: он может возвращать неверную цену, принимать плохой ввод или иметь лишние права.

## Подключение локального примера

Сначала подготовьте и проверьте собственный MCP-сервер, который читает только тестовые маршруты. Предположим, его собранный файл находится в `/absolute/path/trip-tools/server.mjs`. Это путь-заглушка, его нужно заменить.

```bash
claude mcp add --transport stdio --scope local trip-fixtures -- node /absolute/path/trip-tools/server.mjs
claude mcp get trip-fixtures
claude mcp list
```

В сессии откройте `/mcp` и проверьте доступные инструменты. [Документация Claude Code MCP](https://code.claude.com/docs/en/mcp) различает local/user-конфигурацию в `~/.claude.json` и project-конфигурацию в `.mcp.json`. Ранее указанный `.mcp.local.json` не является этим стандартным хранилищем.

Для удалённого сервера выбирайте документированный HTTP-транспорт. Устаревший HTTP+SSE и Streamable HTTP — не одно и то же; утверждение курса, что HTTP исключает серверные сообщения, было неверным. Сверяйте транспорт по [спецификации MCP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports).

## Контракт учебного инструмента

Для `search_trips` определите поля origin, destination и date. В ответе достаточно идентификатора варианта, источника данных, времени получения и цены с валютой. Учебные цены должны быть подписаны как фикстуры.

Проверьте четыре случая: корректный запрос, неизвестный город, неверная дата и отсутствие результатов. «Нет вариантов» не должно превращаться в придуманное предложение. Слишком большой ответ следует ограничить и дать способ запросить детали.

## Что проверить в SDK

Не смешивайте примеры Python и TypeScript. В прежнем тексте TypeScript-клиент импортировал `ClientSession` по неподходящему пути. Этот пример удалён. Возьмите минимальный клиент из [официального TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk), зафиксируйте его версию и сначала проверьте соединение отдельно от LLM.

В production-приложении нужно самостоятельно определить жизненный цикл клиента, завершение соединения, таймауты и отображение MCP-ответа в формат API модели. Claude Code не добавляет эти механизмы вашему backend автоматически.

## Критерий приёмки

Сервер запускается воспроизводимо, публикует ожидаемый инструмент, отклоняет некорректный ввод и не выполняет бронирований. Только после этой проверки добавляйте модель, выбирающую инструмент.
