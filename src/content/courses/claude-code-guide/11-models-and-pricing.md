Выбор модели лучше начинать с набора задач и критериев приёмки. «Дешевле за миллион токенов» не означает «дешевле исправляет ошибку»: повторные попытки и ручная доработка тоже требуют времени.

## Что фиксировать

Запишите точный идентификатор модели, провайдера, настройки, исходный commit и запрос. Алиасы в Claude Code удобны, но их значение может меняться. Не переносите их автоматически в API-код другого провайдера.

Текущие варианты описаны в [настройках моделей](https://code.claude.com/docs/en/model-config). Для цены используйте актуальный биллинг своего аккаунта и официальную тарифную страницу провайдера. Прежняя таблица курса была снимком апреля, а не бессрочным прайсом.

## Таблица собственного сравнения

| Задача              | Принятая правка       | Попытки  | Ручная доработка | Общий расход |
| ------------------- | --------------------- | -------- | ---------------- | ------------ |
| Валидация даты      | Заполнить после теста | Из логов | Минуты           | Из usage     |
| Поиск регрессии     | Заполнить после теста | Из логов | Минуты           | Из usage     |
| Изменение контракта | Заполнить после теста | Из логов | Минуты           | Из usage     |

Пустые ячейки здесь намеренные: это шаблон измерения, не выдуманные результаты. Повторите задачи несколько раз и сохраните неудачи. Если модель решила два случая и сломала третий, этот третий нельзя убрать из отчёта.

## Ограничение запуска

Для print mode документирован `--max-budget-usd`:

```bash
claude -p --max-budget-usd 1.00 "Объясни назначение README без изменения файлов"
```

Этот параметр относится к API-расходам в указанном режиме; проверьте поддерживаемую версию и условия в [CLI reference](https://code.claude.com/docs/en/cli-reference). Он не является лимитом всего аккаунта или всей облачной инфраструктуры. Переменные `CLAUDE_CODE_BUDGET_USD_SESSION` и `CLAUDE_CODE_BUDGET_USD_DAILY` из прежнего текста удалены как неподтверждённый способ контроля.

## Разбирайте перерасход по причине

Сначала найдите самые дорогие задачи. Затем проверьте число итераций, объём ответов инструментов, повторные ошибки и работу помощников. Только после этого меняйте модель. Смена модели не исправляет бесконечный цикл или отсутствие критерия завершения.

Счёт подписки и API-расходы учитываются по-разному; `/cost` не является отчётом «за вчера» для всех сессий. См. [документацию расходов](https://code.claude.com/docs/en/costs).
