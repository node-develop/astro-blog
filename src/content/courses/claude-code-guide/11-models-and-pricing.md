У модели может быть низкая цена за токены, но исправление ошибки всё равно обойдётся дорого: агент сделает несколько попыток, а затем вы будете переделывать результат вручную. Поэтому сравнивать полезнее стоимость законченной задачи, а не только тариф.

Выберите несколько обычных для вашего проекта задач. Например, исправить проверку даты, найти причину падения теста и добавить поле в ответ API. Заранее запишите, как поймёте, что каждая задача решена.

## Сравниваем в одинаковых условиях

Для каждого запуска сохраните исходную версию кода, запрос, настройки и точный идентификатор модели. Короткие имена вроде `sonnet` удобны в Claude Code, но могут обозначать разные версии со временем. Их значение проверяйте в [настройках моделей](https://code.claude.com/docs/en/model-config).

Используйте одну таблицу:

| Задача         | Проверки прошли?        | Число попыток | Время ручной доработки | Расход API |
| -------------- | ----------------------- | ------------- | ---------------------- | ---------- |
| Проверка даты  | Заполнить после запуска | Заполнить     | Заполнить              | Заполнить  |
| Поиск ошибки   | Заполнить после запуска | Заполнить     | Заполнить              | Заполнить  |
| Новое поле API | Заполнить после запуска | Заполнить     | Заполнить              | Заполнить  |

Повторите опыт несколько раз. Сохраняйте неудачные попытки: если исключить их, сравнение будет показывать только удачу. Деньги, время ожидания и время вашей работы лучше записывать отдельно.

## Где смотреть цены

Для прямого API Anthropic есть [официальная тарифная страница](https://platform.claude.com/docs/en/about-claude/pricing). При другом поставщике используйте его тарифы. Учитывайте обычный ввод, чтение и запись кэша, ответ модели и дополнительные платные инструменты, если они используются.

Подписка Claude Code и использование API — разные способы оплаты. `/usage` показывает статистику использования; `/cost` — другое имя той же команды. Сумма в разделе сессии является оценкой, а не итоговым счётом поставщика. Подробности — в [документации стоимости](https://code.claude.com/docs/en/costs).

## Как ограничить отдельный запуск

Режим `-p` выполняет запрос без обычного интерактивного разговора. Для него документирован предел API-расходов:

```bash
claude -p --max-budget-usd 1.00 "Объясни назначение README без изменения файлов"
```

Проверьте поддержку параметра в `claude --help` и [справочнике команд](https://code.claude.com/docs/en/cli-reference). Это ограничение запуска, а не бюджета всего аккаунта или внешних сервисов. Просьба «без изменения файлов» также не заменяет настройки доступа.

## Если расходы выросли

Посмотрите, где именно тратится время и объём запросов: длинные ответы инструментов, повторные ошибки, ненужные помощники, отсутствие условия остановки. Сначала исправьте причину. Более дешёвая модель не поможет, если приложение бесконечно повторяет одну и ту же операцию.
