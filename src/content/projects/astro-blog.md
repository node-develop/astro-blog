## Что работает

Этот сайт объединяет статьи, курс и описание проектов. Исходный код не опубликован: ссылка GitHub ведёт на профиль автора, а не на репозиторий сайта. Версии зависимостей зафиксированы в package.json и lockfile проекта.

Публичные статьи собираются в HTML. PostgreSQL хранит серверные данные, Better Auth обслуживает вход, Pagefind — поиск по публичному контенту. Для программной подачи материалов есть [Content API](/api/v1/openapi.json).

## Проверяемые решения

- [Mermaid при сборке](/blog/mermaid-svg-playwright-build-time/): готовый SVG в HTML вместо рендера диаграммы у читателя.
- [JSON-LD](/blog/json-ld-graph-astro/): общие сведения об авторе и стабильные ссылки между сущностями.
- [robots.txt](/blog/robots-txt-ai-crawlers-2026/): отдельные решения для обхода публичного контента и закрытых маршрутов.

Эти механизмы проверяются сборкой и запросами к опубликованным страницам. Они не доказывают рост CTR или цитирования сами по себе. Прежние неподтверждённые проценты и замеры удалены.
