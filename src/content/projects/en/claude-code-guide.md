## Course goal

Explain the responsibilities of the model and application: context management, tool calls, errors and verification. The intended reader can run a small exercise in a disposable repository.

## September 2026 revision

All 14 lessons were revised. Incorrect SDK examples, obsolete commands and absolute hook-protection claims were corrected. Travel Agent is labeled as a teaching blueprint rather than a ready-made booking service. Unsupported effectiveness percentages were removed.

Start with the [introduction](/en/courses/claude-code-guide/01-introduction/) or inspect the [correction record](/en/courses/claude-code-guide/14-claims-verification/).

## Further work

Add reproducible mini-projects with pinned versions, fixture data and execution records. Length alone does not establish usefulness: readers should be able to repeat a procedure and recognize its failure.
