## Проверка полного цикла

Это временная техническая страница для проверки новой системы публикации. После проверки страница будет удалена.

## Что проверяется

Система принимает Markdown, сохраняет метаданные и изображения, создаёт версию в GitHub и ожидает обновления сайта. Успех подтверждается по точной версии страницы и записи в sitemap.
